VSC Installation & User Guide (Linux)

1. Compile and Install Driver

First, ensure your system is up to date and you have the necessary build tools installed.

sudo apt update
sudo apt install build-essential linux-headers-$(uname -r)

2. Usage Steps

Navigate to the extracted VSC directory and run the setup script.

cd vsc-linux-setup
sudo ./install.sh

3. Common Issues

  • Driver not loading: Check if Secure Boot is disabled in your BIOS.
  • No audio devices found: Restart the audio service using sudo systemctl restart alsa-utils.
